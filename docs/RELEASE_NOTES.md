# ملف التغييرات — Laundry ERP

---

## v2.0.0 — الإصدار التجاري الأول

**التغيير الأهم: نظام ترخيص وتفعيل يعمل دون إنترنت بالكامل.**

### جديد

**التفعيل والترخيص**

- تفعيل المنتج بملفّ `.lkey` واحد — **بلا إنترنت ولا حساب ولا موقع**.
- صفحة **الترخيص** داخل البرنامج: حالة التفعيل، معرّف الجهاز، تصدير طلب التفعيل،
  واستيراد الترخيص.
- تراخيص موقّعة رقمياً بـ RSA-4096 + SHA-256 — لا يمكن تزويرها أو تعديلها.
- ربط بالجهاز يتحمّل تبديل قطعتين من خمس، فالصيانة العادية لا تُوقف العمل.
- **فترة سماح 14 يوماً**: عند انتهاء الترخيص يعمل النظام كاملاً مع تحذير، وبعدها
  يتوقّف إنشاء العمليات الجديدة فقط — **بلا أي حجب للبيانات**.
- تنبيهات تجديد قبل الانتهاء بـ 7 أيام ثم 3 أيام ثم في اليوم الأخير.
- كشف إرجاع ساعة النظام.

**واجهة وهوية**

- حوار **«عن التطبيق»** كامل: الإصدار، حالة الترخيص، بيانات المورّد والدعم، وزرّ
  **«نسخ بيانات الدعم»** الذي يجمع كل ما يحتاجه الدعم الفني بضغطة واحدة.
- شاشة البداية تعرض رقم الإصدار.

### تحسينات

- ملفّ هوية مركزي واحد لبيانات المنتج والدعم والفاتورة.
- المُثبِّت والحزمة يحملان بيانات المورّد والدعم.

### إصلاحات

- **«عن التطبيق» كان يكتب سطراً في السجلّ ولا يعرض للمستخدم شيئاً** — أصبح حواراً كاملاً.

### ملاحظات الترقية

- التحديث من 1.x **لا يمسّ البيانات ولا الإعدادات**.
- بعد الترقية سيطلب البرنامج تفعيلاً. صدّر طلب التفعيل من صفحة الترخيص وأرسله للمورّد.
- خلال فترة السماح يعمل النظام كاملاً، فلا داعي للعجلة.
